# Contributing

Thanks for helping improve Windows Shortcut Control.

## Good Contributions

You can contribute through:

- bug reports;
- reproducible compatibility reports;
- feature requests;
- UI/UX suggestions;
- documentation fixes;
- tested patches submitted by Pull Request after discussion.

## Before Opening an Issue

Please include:

- Windows version;
- application version;
- steps to reproduce;
- expected behavior;
- actual behavior;
- screenshot when relevant;
- Self Diagnostics result when relevant.

Remove sensitive information before posting logs or screenshots.

## Pull Requests

Before submitting code:

1. Open an Issue for non-trivial changes.
2. Keep the single-file portable architecture unless the change has been discussed.
3. Keep compatibility with Windows PowerShell 5.1 unless explicitly changing requirements.
4. Test both Indonesian and English UI where the change affects visible text.
5. Do not add external network dependencies without discussion.
6. Do not include secrets, tokens, personal data, generated backups, or machine-specific paths.
