# Changelog

All notable public changes to **Windows Shortcut Control** will be documented here.

The project follows a simple versioning format:

```text
MAJOR.MINOR.PATCH
```

## [3.2.1] - 2026-08-27

### Initial Public Release

This release publishes the current Windows Shortcut Control codebase as the
first structured GitHub release.

Current feature set includes:

- single-file CMD + embedded PowerShell/WPF application;
- Dashboard, Shortcuts, Windows Tools, System Info, Settings, and About;
- Folder, File, App, URL, and PowerShell shortcuts;
- pin, favorites, recent items, and usage counters;
- drag & drop shortcut creation;
- global search and Command Palette;
- System Tray integration;
- optional Windows startup registration;
- global hotkey support;
- live CPU, RAM, and network monitoring;
- JSON shortcut import/export;
- full configuration backup/restore;
- Last Known Good recovery;
- self diagnostics;
- Indonesian and English UI;
- single-instance activation.
