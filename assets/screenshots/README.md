# Screenshots

Add clean screenshots here before publishing the repository.

Recommended names:

```text
dashboard.png
shortcuts.png
windows-tools.png
system-info.png
settings.png
guide.png
about.png
```

Before uploading screenshots:

- hide personal file paths;
- hide computer/user names if you do not want them public;
- hide private shortcut targets;
- hide local IP addresses if unnecessary;
- use a consistent window size;
- preferably capture the same application theme/language.
